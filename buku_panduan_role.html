BUKU PANDUAN APLIKASI REGISTER PROPOSAL & PO

Panduan Teknis Berdasarkan Hak Akses Pengguna (Role: Dev, Admin, Manager)

1. ROLE: DEVELOPER / SUPER ADMIN (dev)

Akses penuh lintas departemen untuk pemeliharaan dan pengawasan sistem.

Tanggung Jawab:

  • Mengawasi seluruh log dan aktivitas lintas departemen.
  • Menangani isu teknis atau kendala database.

Workflow:

  1. Login akun dev.
  2. Melihat rekap global seluruh departemen pada dashboard.

2. ROLE: ADMIN DEPARTEMEN (admin)

Pengelola administrasi harian dan pembuatan dokumen proposal/PO per departemen.

Tanggung Jawab:

  • Membuat draf, mengisi data, dan mengajukan proposal/PO.
  • Mencetak dokumen resmi ke format PDF.
  • Mencatat hasil approval lanjutan (Korea).

Workflow:

  1. Login akun admin sesuai departemen.
  2. Buat draf proposal/PO baru, lalu simpan.
  3. Ajukan dokumen untuk masuk ke status Pending Local.
  4. Cetak PDF jika dokumen sudah disetujui.

3. ROLE: MANAGER LOKAL / DEPARTEMEN (manager)

Pemberi otorisasi awal dan persetujuan lokal atas proposal/PO yang diajukan.

Tanggung Jawab:

  • Memeriksa proposal atau PO yang berstatus Pending Local.
  • Memberikan keputusan setuju atau tolak/revisi.

Workflow:

  1. Login akun manager.
  2. Cek daftar dokumen di To-Do List dashboard.
  3. Klik Setujui (Approved Local) atau Tolak/Revisi.
