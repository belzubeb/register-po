PANDUAN PENGGUNAAN APLIKASI REGISTER PROPOSAL & PO

Panduan Berdasarkan Hak Akses (Role) Pengguna — PHP Native (XAMPP PHP 7.4)

1. Pendahuluan

Aplikasi Register Proposal & PO membagi hak akses pengguna (role) untuk memastikan keamanan data dan kejelasan tanggung jawab operasional.

2. Hak Akses & Fitur Per User

A. Administrator (Admin)

  • Manajemen User: Menambah, mengubah, atau menghapus akun dan hak akses pegawai.
  • Full CRUD: Mengelola (tambah, edit, hapus) seluruh data proposal dan PO dari semua divisi.
  • Laporan & Rekap: Mengakses laporan rekapitulasi keseluruhan dan ekspor dokumen.

B. Staff / User Biasa

  • Input Dokumen: Membuat entri proposal atau PO baru.
  • Kelola Data Mandiri: Mengubah data proposal/PO milik sendiri yang belum dikunci.
  • Cetak PDF: Mencetak dokumen resmi proposal atau PO ke format PDF.

3. Alur Penggunaan (Workflow)

  1. Login: Akses http://localhost/register-po, masukkan kredensial akun.
  2. Input: Masuk ke menu Proposal/PO -> Klik Tambah -> Isi form -> Simpan.
  3. Cetak: Klik tombol PDF pada data yang ingin dicetak.
  4. Validasi (Admin): Admin memeriksa, menyetujui, atau merevisi data yang masuk.
